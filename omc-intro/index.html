발표를 이루는 네 가지 주제

발표 자료에 담긴 흐름을 먼저 훑어보고, 슬라이드에서 구체적인 사례와 설명을 확인하세요.

  1. 01

    Harness Engineering

    잘 작성한 프롬프트 하나에 머무르지 않고, 지침·도구·맥락·작업 절차가 함께 작동하는 AI 환경을 살펴봅니다.

  2. 02

    Oh-my-Claude-Code

    Claude Code 위에서 여러 에이전트와 기능을 조율하는 OMC의 역할과 발표자가 소개하는 사용 철학을 정리합니다.

  3. 03

    OMC 활용 경험

    슬라이드 제작과 반복 작업처럼 코딩 외 업무까지 확장해 활용한 발표자의 사례를 확인합니다.

  4. 04

    Skill 시스템

    반복해서 쓸 지침을 SKILL.md에 담고, 개인 또는 프로젝트 단위에서 호출하는 구성 방식을 소개합니다.

주요 내용

  • Prompt에서 Harness로 넓어지는 관점
  • OMC의 주요 기능과 작업 흐름
  • 업무 활용 사례와 Skill 재사용
