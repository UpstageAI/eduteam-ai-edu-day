## Google Apps Script란?

### GAS의 특징

- **Google이 공식 제공하는 클라우드 기반 업무 자동화 도구**입니다.
- JavaScript 문법을 기반으로 돌아가지만 **코드를 직접 작성할 필요가 없습니다** — 우리가 할 일을 설명하면 AI가 대신 코드를 짜 줍니다.
- 웹 브라우저에서 곧바로 실행되므로 내 컴퓨터에 별도의 프로그램을 설치할 필요가 없습니다.
- Google 계정만 있다면 누구나 **무료**로 사용할 수 있습니다.

### GAS로 제어할 수 있는 서비스

| 서비스 | 자동화할 수 있는 작업 |
|--------|--------------|
| Google Sheets | 데이터 일괄 정리, 복잡한 계산, 시트 간 자동 입력 및 취합 |
| Google Drive | 규칙에 따른 폴더 생성, 대량 파일 이동 및 분류, 폴더 구조 파악 |
| Google Docs | 템플릿 기반 문서 자동 생성, 본문 내용 채우기 |
| Gmail | 맞춤형 이메일 대량 자동 발송, 특정 메일 읽어 오기 |
| Google Calendar | 시트 데이터 기반 일정 자동 등록 및 조회 |
| Google Forms | 설문 응답 데이터 실시간 처리 및 알림 연결 |

### Apps Script 에디터 열기

1. **Google Sheets**에서 실습용 스프레드시트를 엽니다.
2. 상단 메뉴에서 **확장 프로그램** → **Apps Script**를 차례로 클릭합니다.
3. 새 브라우저 탭이 열리며 코드 에디터 화면이 나타납니다.
4. 에디터 창에 AI가 짜 준 코드를 붙여넣고 상단의 **▶ 실행** 버튼을 누릅니다.

> **처음 코드를 실행할 때는 권한 승인 팝업이 나타납니다.** 당황하지 말고 '권한 검토' 및 '허용'을 눌러 진행하세요. 내가 작성한 스크립트가 내 Google 계정의 시트와 드라이브 데이터에 접근할 수 있도록 허락해 주는 정상적인 보안 절차입니다.

## AI에게 잘 물어보는 법

AI(ChatGPT, Claude)는 질문이 구체적이고 맥락이 뚜렷할수록 한 번에 제대로 돌아가는 코드를 내놓습니다. 아래 다섯 단계 공식만 기억하면, 코딩 경험이 전혀 없어도 실무에 바로 쓸 수 있는 깔끔한 코드를 얻을 수 있습니다.

### 프롬프트 작성 공식

| 순서 | 항목 | 작성 예시 |
|------|------|------|
| 1 | **도구 지정** | "Google Apps Script로 ~하고 싶어" |
| 2 | **현재 상황** | "내 스프레드시트에 ~한 시트와 데이터가 있어" |
| 3 | **문제점** | "~형식이 제각각이야 / ~이 빠져 있어서 불편해" |
| 4 | **할 일** | 원하는 작업을 순서대로 번호 매겨 나열 (1, 2, 3...) |
| 5 | **제약 조건** | "Google Apps Script 문법으로 작성해 줘 (var 사용)" |

> **핵심**: AI가 내 화면을 직접 보지 못한다고 생각하고, **현재 데이터 구조와 원하는 결과를 구체적으로** 적어 주는 것이 비결입니다.

### 프롬프트 템플릿

실무에서 새로운 자동화를 시도할 때는 아래 빈칸을 채워 AI에게 건네 보세요.

```
도구: Google Apps Script로 ________________ 하고 싶어.

현재 상황:
- 현재 데이터/파일이 어떤 상태인지 구체적으로 설명

문제점:
- 무엇이 잘못되었는지 / 수작업으로 할 때 어떤 점이 불편한지

할 일:
1) 구체적인 작업 1
2) 구체적인 작업 2
3) ...

Google Apps Script 문법으로 작성해줘 (var 사용).
```

### 에러가 났을 때

**에러가 나는 것은 지극히 자연스러운 과정입니다!** 숙련된 개발자도 한 번에 에러 없이 코드를 짜는 일은 드뭅니다. 빨간 에러 메시지가 떠도 당황하지 마세요.

1. 화면에 뜬 **에러 메시지**와 에디터에 넣었던 **현재 코드**를 그대로 복사합니다.
2. AI에게 함께 붙여넣으며 이렇게 요청합니다: **"이 에러가 났어. 수정해 주고, 무엇이 문제였는지 간단히 설명도 해 줘."**
3. 프롬프트를 보낼 때 각 단계마다 실행 로그(`Logger.log`)를 남겨 달라고 요청해 두면, 어디서 문제가 생겼는지 파악하기가 훨씬 수월해집니다.

### 결과가 예상과 다를 때

- 에러 없이 실행은 끝났는데 시트나 폴더에 나타난 결과가 내 의도와 다를 때가 있습니다.
- 이때는 **내가 기대했던 결과**와 **실제로 나타난 결과(또는 실행 로그)**를 나란히 적어 AI에게 보내세요.
- "에러는 안 나는데 결과가 내 예상과 달라. 왜 차이가 나는지 원인을 찾고 코드를 수정해 줘"라고 요청하면 됩니다.

### 개인정보 주의사항

- 외부 LLM에 데이터나 실행 로그를 붙여넣을 때는 실제 이름, 이메일, 전화번호를 반드시 **마스킹(가림 처리)**하세요.
- 사내 비공개 Drive URL이나 고유 폴더 ID는 외부 AI에 그대로 공유하지 않는 것이 안전합니다.
- 오늘 실습에서 다루는 지원자 명단과 파일은 **모두 가짜 샘플 데이터**이므로 안심하고 실습하셔도 됩니다.

## Practice 1: 스프레드시트 정규화 (Beginner)

**예상 소요시간**: 약 10분

### 목표

뒤죽박죽인 50명의 지원자 데이터를 일관된 형식으로 깔끔하게 다듬고, 다른 시트에 흩어져 있는 이메일 주소를 찾아 연결합니다.

### 입력 데이터

| 시트 | 컬럼 구성 | 데이터 규모 |
|------|------|-------|
| Sheet1 | 이름, 나이, 지원트랙, 지원동기, 연락처 | 지원자 50명 |
| Sheet2 | 이름, 이메일 | 42명 (8명은 이메일 누락) |

### 해결할 문제점

- 이름 글자 사이에 불필요한 공백이 끼어 있는 행이 있습니다 (예: `"이  준"`).
- 전화번호 표기 형식이 사람마다 제각각입니다 (예: `010 1234 5678`, `010-1234-5678`, `+82-10-1234-5678`).
- Sheet2에 이메일 정보가 아예 없는 지원자가 8명 있어서, 매칭 실패 시 별도 표시가 필요합니다.

### 프롬프트

아래 프롬프트를 복사해 ChatGPT 또는 Claude 입력창에 **그대로** 붙여넣으세요.

> **팁**: 코드가 뒤에서 어떤 작업을 수행하는지 한눈에 확인할 수 있도록, LLM에게 각 단계마다 로그(`Logger.log`)를 남겨 달라고 덧붙이는 것을 추천합니다.

```
Google Apps Script로 스프레드시트 데이터를 정리하고 싶어.

현재 상황:
- 내 스프레드시트에 시트가 2개 있어
- Sheet1: 이름, 나이, 지원트랙, 지원동기, 연락처
- Sheet2: 이름, 이메일

문제점:
- 이름에 공백이 들어가 있는 경우가 있음 (예: "이  준")
- 연락처 형식이 제각각임 (010 1234 5678, 010-1234-5678, +82-10-1234-5678 등)
- Sheet2에 이메일이 있는데, 이름으로 매칭해서 Sheet1 데이터와 합치고 싶음

할 일:
1) 이름 공백 정리
2) 연락처를 010-1234-5678 형식으로 통일
3) Sheet2에서 이름으로 이메일 찾아서 매칭
4) 정리된 결과를 새 시트에 저장
5) 이메일 못 찾은 사람은 표시해줘
6) 몇 명 처리했는지 로그로 알려줘

Google Apps Script 문법으로 작성해줘 (var 사용).
```

### 실습 순서

1. 위 프롬프트를 복사해 ChatGPT 또는 Claude에 보내고 코드를 받습니다.
2. 생성된 코드를 복사해 Apps Script 에디터에 붙여넣고 저장합니다.
3. 상단의 **▶ 실행** 버튼을 누른 뒤, 스프레드시트로 돌아가 새로 만들어진 결과 시트를 확인합니다.

### 기대 결과

- 스프레드시트 하단에 새 결과 시트(예: `"정규화_지원자_목록"`)가 생성됩니다.
- 모든 지원자 이름에서 불필요한 공백이 깔끔하게 사라집니다.
- 제각각이던 연락처가 `010-xxxx-xxxx` 형식으로 일괄 통일됩니다.
- Sheet2의 이메일 주소가 각 지원자 행에 정확히 합쳐집니다.
- 이메일을 찾지 못한 8명의 칸에는 `"매칭 실패"` 등의 표시가 남습니다.

## Practice 2: Drive 폴더/문서 생성 (Intermediate)

**예상 소요시간**: 약 10분

### 목표

Practice 1에서 깨끗하게 정리한 지원자 데이터를 바탕으로, Google Drive에 지원 트랙별 하위 폴더를 만들고 각 지원자의 자기소개 문서를 자동으로 생성해 넣습니다.

### 기대 결과 구조

```
트랙별_지원자/
├── SeSAC/
│   ├── 김민지.docx
│   ├── 정서윤.docx
│   └── ...
├── SSAFY/
│   ├── 이준.docx
│   └── ...
├── KDT/
├── Hackathon/
└── BootCamp/
```

생성된 각 문서 안에는 해당 지원자의 이름, 지원 트랙, 지원동기가 자동으로 채워집니다.

### 프롬프트

아래 프롬프트를 복사해 ChatGPT 또는 Claude에 **그대로** 입력하세요.

> **팁**: 파일 생성 작업은 시간이 조금 걸릴 수 있으므로, 진행 상황을 볼 수 있게 각 단계마다 로그(`Logger.log`)를 남겨 달라고 요청하면 더욱 좋습니다.

```
Google Apps Script로 Drive에 폴더와 문서를 자동으로 만들고 싶어.

현재 상황:
- 아까 정리한 지원자 데이터가 스프레드시트에 있어
- 시트에 이름, 지원트랙, 지원동기 등이 있어

할 일:
1) Drive에 "트랙별_지원자" 폴더를 만들어줘
2) 지원트랙별로 하위 폴더를 만들어줘 (예: SeSAC, SSAFY 등)
3) 지원자마다 "이름.docx" 문서를 만들어서 해당 트랙 폴더에 넣어줘
4) 문서 안에 지원자 이름, 트랙, 지원동기를 적어줘
5) 같은 이름 파일이 이미 있으면 건너뛰고 로그만 남겨줘
6) 트랙별로 몇 개 만들었는지 요약해줘

Google Apps Script 문법으로 작성해줘 (var 사용).
```

### 실습 순서

1. 위 프롬프트를 복사해 LLM에 보내고 코드를 받습니다.
2. 받은 코드를 Apps Script 에디터에 붙여넣고 실행합니다.
3. 내 **Google Drive**를 열어 `"트랙별_지원자"` 폴더와 하위 트랙 폴더, 그리고 지원자별 문서들이 제대로 만들어졌는지 직접 확인합니다.

## Practice 3: 폴더 구조 파악 (Advanced Prep)

**예상 소요시간**: 약 10분

### 목표

Google Drive 안에 복잡하게 얽혀 있는 폴더와 파일 목록을 Google Sheet에 한눈에 들어오는 트리(tree) 형태로 펼쳐 봅니다. 마지막 단계인 Practice 4(파일 자동 분류)에 들어가기에 앞서, 현장을 먼저 정찰하고 규칙을 찾아내는 준비 단계입니다.

### 상황 설명

현재 `"GAS_Tutorial_Workspace"` 폴더 안을 들여다보면:
- 총 72개의 파일이 18개의 크고 작은 하위 폴더에 어지럽게 뒤섞여 있습니다.
- 파일 이름 앞머리에는 `[SeSAC]`, `[SSAFY]`, `[Ext]` 같은 대괄호 태그들이 붙어 있습니다.
- 무작정 파일을 옮기기 전에, 전체 폴더 구조와 파일 이름 패턴을 먼저 파악해야 정확한 정리 규칙을 세울 수 있습니다.

### 프롬프트

아래 프롬프트를 복사해 ChatGPT 또는 Claude에 **그대로** 입력하세요.

> **팁**: 탐색 진행 과정을 확인할 수 있도록 LLM에게 로그(`Logger.log`) 출력을 함께 요청하는 것을 권장합니다.

```
Google Apps Script로 Drive 폴더 구조를 Google Sheet에 정리해서 보고 싶어.

현재 상황:
- "GAS_Tutorial_Workspace"라는 폴더 안에 하위 폴더가 여러 개 있어
- 어떤 구조인지 파악이 안 돼서 시트에 트리 형태로 보고 싶어

할 일:
1) 폴더 이름으로 루트 폴더를 찾아줘
2) 하위 폴더와 파일을 전부 탐색해서 시트에 적어줘
3) 들여쓰기로 깊이를 표현해줘 (폴더 안의 폴더는 더 안쪽으로)
4) 폴더인지 파일인지 구분이 되면 좋겠어
5) 전체 경로도 같이 보여줘
6) 마지막에 폴더 몇 개, 파일 몇 개인지 요약해줘
```
