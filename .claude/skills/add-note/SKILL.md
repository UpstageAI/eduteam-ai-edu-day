# 쪽지 추가

`notes.md`에 블록 하나를 더하면 끝난다. 새 파일도, 카드도, 테스트 목록도 건드리지 않는다. 벽은 이 파일을 읽어 그린다.

## 형식

**맨 아래에 덧붙인다.** 목록에는 최근 것부터 보인다.

```
## 말
kind: term
한 줄 설명. 두 줄 이상 쓰면 한 문단으로 이어 붙는다.
https://링크
https://링크가-여럿이면-한-줄에-하나씩
```

- `## 말` 바로 아래의 `key: value` 줄만 메타데이터로 읽는다. 설명이나 링크가 한 줄이라도 나온 뒤에 오는 `key: value`는 그냥 본문이다.
- 설명과 링크는 없어도 된다. 말만 있어도 쪽지가 된다.

## 갈래 선택

| kind | 언제 | 모서리 |
|---|---|---|
| `repo` | 코드 저장소 | 초록 |
| `link` | 나중에 찾아갈 문서나 도구 | 초록 |
| `term` | 알아 둘 말 | 빨강 |

안 적으면 `term`이다. **링크가 붙어 있다고 `repo`나 `link`가 되지 않는다.** 용어 설명에 출처 링크를 다는 일이 흔하므로, 그 쪽지의 본체가 무엇인지로 고른다. 예를 들어 `meat proxy`는 참고 링크가 있어도 `term`이고, `Design Diagram`은 저장소 자체가 요점이라 `repo`다.

모르는 값을 적으면 초록이 되지 않고 `term`으로 떨어진다.

## 설명 작성

쪽지는 정사각형이라 설명이 다섯 줄을 넘으면 잘린다. 두세 줄로 끝낸다.

뜻을 지어내지 않는다. 처음 보는 말이면 찾아보고, 확실하지 않으면 사용자에게 묻는다. 링크 주소는 `host/마지막칸`으로 줄여 보이므로 길어도 괜찮다.

## 검증

```bash
node --test tests/*.test.cjs
```

벽이 실제로 그려지는지는 홈을 열어 확인한다. 파일이 비어 있거나 읽히지 않으면 벽 전체가 숨겨지고 위쪽 자료 목록은 그대로 남는다.
