01 / AI 에이전트

LLM 에이전트의 외재화

모델의 능력과 모델을 둘러싼 구조를 구분해서 읽기.

논문 읽기한국어 해설입문 약 5분
읽기 전에
외재화는 에이전트에 필요한 기억, 작업 방법, 도구 사용 규칙을 모델 밖에 두는 접근입니다. 이 자료는 네 가지 개념을 연결해 설명합니다.

모델 밖에 두는 네 가지 구조

모든 정보를 프롬프트에 담는 대신, 필요한 정보를 저장하고 꺼내 쓰는 구조를 갖춥니다. 각 구조가 맡는 역할부터 살펴보세요.

01 / MEMORY

메모리

이전 작업의 정보와 상태를 저장해 다음 작업에서도 참고합니다.

02 / SKILLS

스킬

반복해서 쓰는 절차와 노하우를 재사용 가능한 형태로 정리합니다.

03 / PROTOCOLS

프로토콜

에이전트와 도구가 정보를 주고받는 형식과 규칙을 정합니다.

04 / HARNESS

하니스

실행 순서, 권한, 검증, 실패 처리를 담당하는 운영 환경입니다.
